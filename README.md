# A股每日技术面三维复盘

每日 A 股收盘后自动生成的技术面复盘报告（HTML）。

## 内容

- 首屏结论 / 风险面 / 进攻面 / 情绪面
- 主线板块 / 三档建仓参考 / 次日观察清单 / 风险提示
- 大盘位置与支撑压力 / 量能与资金面 / 多周期共振
- 领涨领跌特征 / 仓位与节奏建议
- 中英双语切换，纯 SVG 图表，离线可打开

## 文件结构

| 文件 | 说明 |
|------|------|
| `index.html` | 最新交易日报告（Cloudflare Pages 入口） |
| `技术面复盘_YYYYMMDD.html` | 按日期归档的历史报告 |

## 自动化

每个交易日（周一至周五）16:00 CST 自动生成并推送。
